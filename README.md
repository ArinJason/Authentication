# Bearer Auth MVC

## Overview
This is a **Node.js backend project** demonstrating user authentication and authorization using **JWT (JSON Web Tokens)** and **Bearer tokens**.  
The project follows the **MVC architecture** and uses **MongoDB Atlas** as the database.  
All APIs are tested using **Postman**.

---

## Tech Stack
- Node.js
- Express.js
- MongoDB Atlas (Mongoose)
- JWT (JSON Web Tokens)
- Postman for API testing

---

## Features
- User Registration (hashed passwords using bcrypt)
- User Login (JWT token generation)
- Protected Routes (Bearer token authorization)
- MVC folder structure for clean code
- Error handling and validation
